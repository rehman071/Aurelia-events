# Aurelia-events
Aurelia Events — Couture Event Architecture & Bespoke Experiences

Curating Moments of Timeless Grandeur.

An editorial, luxury event management web experience crafted for an international atelier designing candlelit couture weddings, architectural corporate summits, and private soirées across New York, Paris, Mumbai, and Dubai.

Live Website: https://aureliaeventsman.vercel.app/

Overview

Aurelia Events is a modern, interactive single-page web application built to showcase high-end event architecture with understated elegance, clear visual hierarchy, and functional client booking workflows. Rather than relying on static brochures, the platform pairs editorial storytelling with interactive filtering, tier toggles, real-time consultation forms, and an instant Digital VIP Pass generator.

Key Features

1. Editorial Hero & Animated Key Metrics

Full-viewport luxury hero section introducing Aurelia — Bespoke Event Architecture (Est. 2014) with primary calls to action (Commission an Event and Explore Calendar).

Animated milestone counters highlighting Bespoke Events, Client Retention, Iconic Venues, and Years of Craft.

Smooth responsive navigation bar with a numbered editorial mobile drawer (01–06) and global atelier locations (New York • Paris • Mumbai • Dubai).

2. The Atelier of Experiences (#services)

Presents six specialized event disciplines:

Couture Weddings

Executive Summits

Symphony & Live Galas

Luxury Brand Launches

Milestone Soirées

Global Hybrid Forums

3. Curated Calendar (#events) & Digital VIP Pass Flow

Season 2026 – 2027 showcase of upcoming flagship galas, executive forums, and couture events.

Interactive Category Filters: Filter listings dynamically across All, Corporate, Music & Gala, and Expo & Tech.

Seat Reservation Modal: Allows guests to select 1–4 seats, view live admission total calculation, and instantly generate an Official Digital VIP Admission Pass complete with a unique confirmation code and one-click Copy Code utility.

4. Bespoke Collections (#packages)

Interactive switcher to toggle seamlessly between Social Soirées and Corporate Galas.

Structured, transparent production tiers:

Essential Spark

Signature Couture (Most Requested)

Imperial Bespoke

5. Voices of Distinction (#testimonials) & The Visionaries (#team)

Patron Reflections Carousel: Features curated client testimonials with a toggleable Auto-Play control.

Creative Leadership Showcase: Highlights the architects, scenographers, and production directors behind the atelier.

6. Private Concierge (#contact) & Consultation Modal

Flagship Atelier Information: Displays SoHo Design District (New York) headquarters, global ateliers, hours, and one-click Copy buttons for both the Private Line and Atelier Desk email.

Event Inquiry Dossier Form: Validated form capturing client details, experience category, preferred date, estimated investment tier ($10,000 to $150,000+ Bespoke Imperial), and creative vision notes with an interactive confirmation state.

Commission an Event Modal: Accessible from anywhere on the page for quick private consultation requests with discipline and collection tier pre-selection.

The Aurelia Dispatch: Footer newsletter signup for seasonal scenography essays and private salon invitations.
